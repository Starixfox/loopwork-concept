# Agora — concept demo

Static demo of a bilingual (EN / NL) marketing site for Agora, an AI workflow
automation consultancy.

- **Live**: https://starixfox.github.io/loopwork-concept/
- **Dutch version**: https://starixfox.github.io/loopwork-concept/nl/

Built with Next.js (static export) from the `loopwork-export` wrapper in
[Starixfox/coursehub](https://github.com/Starixfox/coursehub). This repo
contains only the generated build output; edit the source there and re-export
to update.
